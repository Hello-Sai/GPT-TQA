# GPT-Text Based Q&A Agent

# Ensure all dependencies are met before running
    # You must have Ollama running with 'mistral' model installed locally
    # You can download using it here https://ollama.com/download/
    

## Clone the repository in your terminal 

```bash
git clone https://github.com/Hello-Sai/GPT-TQA/
```

## Setup Virtual Environment & Install Libraries

```bash
  python3 -m venv .venv
  source .venv/bin/activate

  # .venv\Scripts\activate (if windows)

  pip install -r requirements.txt
```

## Build and Run Agent in Your Local System

```bash

  python3 main.py
```
## The exact template is 
Input : Question
output : answer (from agent)
